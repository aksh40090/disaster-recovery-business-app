# Failover Test Evidence

This folder contains evidence collected during the Disaster Recovery failover test.

## Evidence to be collected

1. Screenshot showing the application running in the primary region.
2. Evidence of the simulated primary-region failure.
3. Screen recording showing the failover process.
4. Screenshot showing the application recovered in the secondary region.
5. Timestamps used to calculate the actual RTO.
6. Evidence of data availability after recovery.

## Test Flow

Primary Region
→ Simulated Failure
→ Failover
→ Secondary Region
→ Application Recovery

## Important Note

Actual screenshots, recordings, timestamps, and test results will be added after the real failover test is performed.

No simulated or fabricated test results will be used.
